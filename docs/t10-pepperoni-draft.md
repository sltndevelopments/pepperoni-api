# Черновик T10 — содержание для `/pepperoni`

На сайт не публиковать. 301 в этом документе нет. Сначала эти разделы должны появиться на целевых страницах, и только после отдельного разрешения — редиректы.

Факты ниже уже есть в каталоге и на текущих страницах: KD-013 нарезка 0,5 кг, KD-014 батон 0,8 кг, варёно-копчёная из мяса кур, калибр 50–55 мм, −18 °C, 360 суток, халяль ДУМ РТ № 614A/2024. Замера «не скручивается при 350 °C» нет — в текст его не переносить.

## Раздел «Для пиццерий» на `/pepperoni`

Источник смысла: `/pepperoni-dlya-pizzerii`.

- Что это: варёно-копчёная халяль-пепперони для пиццы, производство в Казани.
- Два формата поставки: нарезка KD-013, 0,5 кг, и целый батон KD-014, 0,8 кг.
- Калибр 50–55 мм. Поведение в печи на этой странице не обещать: его проверяют образцом на оборудовании покупателя.
- Для кого: пиццерии и сети. Ссылка на `/dlya-horeca`.
- Минимум — одна паллета, сборная возможна. Цены EXW Казань. Образец согласуется отдельно.
- Заявка и WhatsApp ведут на ту же форму, что уже стоит на `/pepperoni`.

## Раздел «Нарезка и батон» на `/pepperoni`

Источник смысла: `/pepperoni-v-narezke`.

- Нарезка KD-013 уже нарезана, батон KD-014 режет покупатель.
- Таблица: SKU, формат, масса, хранение, срок, цена из `products.json`.
- Когда брать нарезку: линия, где нет слайсера или нужна одинаковая порция.
- Когда брать батон: своя толщина ломтика.
- Не писать «1 кг» для KD-014.
