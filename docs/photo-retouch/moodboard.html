Что даёт «модность»

РычагКаталог (было)Punch (цель)
СветМягкий со всех сторонКлюч сбоку + блик + тень
ФонСеро-белый#FFF или brand color
ЦветNeutral / mutedHSL: Red/Yellow/Green +
CropМного воздухаКрупнее, diagonal / macro
СтайлингСухо, идеальноСок, живой соус, хруст лука
Не цель

Перегретый оранжевый фильтр, грязный вырез фона, «Instagram soap» по всему кадру.

Цель

Чистый punch: красный кетчуп, жёлтая горчица, читаемая тень, бренд-системный фон.
