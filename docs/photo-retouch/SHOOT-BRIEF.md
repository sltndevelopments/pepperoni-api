# Shoot brief — hot dog / sausage hero (1 день)

Цель: 6–8 кадров, которые несут «модность» **ещё со съёмки**, а не только из Lightroom.

## Setup

| | |
|---|---|
| Фон A | Чистый белый (#FFF), бесшовный |
| Фон B | Brand burgundy `#3A1412` или горчица `#C9A227` (1–2 кадра) |
| Ключ | Жёсткий / полужёсткий сбоку-сверху (beauty dish / small softbox близко) |
| Fill | Отражатель белый, −1…−1.5 stop от ключа |
| Камера | 50–85mm, f/4–5.6 для hero; f/2.8 для macro tip |
| WB | 5200–5600K (не «холодный каталог») |

**Обязательно в кадре:** блик на кетчупе или колбасе + читаемая тень.

## Стайлинг

1. Колбаса с гриля — чуть жира/сока, не матовая «пластик».
2. Кетчуп свежий, насыщенный; горчица — яркая, линия живая (не линейка).
3. Лук хрустящий, сухой (не раскисший).
4. Огурцы — ярко-зелёные, тонкие слайсы.
5. Булка слегка подсушена/поджарена по краю.

## Shot list (обязательный)

1. **Hero classic diagonal** — с луком, ¾, фон белый  
2. **Hero classic side** — кетчуп+горчица+огурцы, без лука или с  
3. **French dog macro** — выход колбасы + соус, shallow DOF  
4. **French dog vertical** — на burgundy фоне  
5. **Hand-held top-down** — рука + хот-дог (lifestyle punch)  
6. **Detail onions** — crop на текстуру лука/горчицы  
7. **Pack + product** (если есть упаковка Money SKU)  
8. **Safety white** — чистый каталог для маркетплейса

## Что снимать запрещено как hero

- Серый грязный фон  
- Полный softbox «без тени»  
- Кадры с размазанным соусом по столу (брак, не стиль)  
- Слишком широкий crop с пустым воздухом 60%+ кадра  

## После съёмки

1. Отбор 8–12 кадров  
2. Пресет [`KD Punch Hotdog v1`](KD-PUNCH-PRESET.md)  
3. Фон: довести до #FFF или brand color  
4. Экспорт: web JPEG sRGB 2000–2400 px long side + master TIFF/PSD
