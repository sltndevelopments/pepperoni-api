## Сервер

`pepperoni-vps`, `/var/www/pepperoni/repo`: `HEAD` = `origin/main` = `caa4605dd`.
`git status`: 157 изменённых файлов, 28 неотслеживаемых, из них 131 HTML в `public/`.

Источник истины:

| Что | Источник | Почему |
|---|---|---|
| Код, структура страниц, allowlist | `origin/main` | рабочее дерево сервера — вывод cron, не редактура |
| Цены, курсы, дата каталога | Google Sheets через `sync-vps.sh` | 124 карточки отличаются только строкой экспортных цен; прайсы и `products.json` — тем же |
| Дата в sitemap, rss, описаниях категорий | тот же sync | `2026-10-05` в git, `2026-10-06` на сервере |
| Текст «смотрите также» на 5 хабах | генератор в git отстаёт от HTML на сервере | незалинкованный текст стал ссылкой; в генераторе этого нет, следующий прогон вернёт git-вариант |
| `/about` | git как последняя зафиксированная страница, но оба дерева уже сломаны | см. ниже |

Не коммитить рабочее дерево сервера целиком. `git reset --hard` на деплое сотрёт курсы до следующего sync (около 10 минут) и лишние `</div>` на `/about`. Четыре незакоммиченные записи `noindex` в серверном `index_manifest.json` (`/blog/chak-chak`, `/blog/cheburek-zharenyj`, `/blog/elesh`, `/dashboard`) в git отсутствуют. В этой фазе они не переносятся.

## Почему ломается `/about`

`scripts/render_static_catalog.py` заменял блок `live-sku-list` до первого `</div>`. Это закрывает только внутреннюю сетку. Каждый запуск `sync-vps.sh` оставлял ещё один `</div>`.

На момент снимка: git `68` открывающих и `746` закрывающих; живой `https://pepperoni.tatar/about` — `68` и `1007`. Ссылки внутри блока те же.
