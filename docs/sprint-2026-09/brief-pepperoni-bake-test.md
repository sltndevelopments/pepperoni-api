# Бриф: реальное испытание пепперони при выпечке (для статьи и /pepperoni)

Цель: единственный новый материал этого месяца по пепперони, который нельзя написать без
данных. Агент не сочиняет результаты — технолог проводит испытание, агент оформляет.

## Что испытываем
- KD-013 «Пепперони варёно-копчёный куриный, нарезка» (0,5 кг) и KD-014 батон (0,8 кг),
  нарезанный на производстве и на слайсере пиццерии.

## Протокол (заполняет технолог)
| Параметр | Значение | Как измерено |
|---|---|---|
| Толщина ломтика, мм | | штангенциркуль, 10 ломтиков, среднее |
| Диаметр ломтика до выпечки, мм | | |
| Диаметр после выпечки, мм (усадка %) | | |
| Ломтиков в упаковке 0,5 кг, шт | | пересчёт 3 упаковок |
| Масса ломтика, г | | |
| Печь / режим | | подовая / конвейерная / конвектомат, t °C, время |
| Выделение жира | | фото; субъективно: нет / умеренно / сильно |
| «Чашечка» (cupping) | | да / нет, фото |
| Расход на пиццу 30 см при 25 / 35 ломтиках, г | | расчёт |
| Хранение открытой упаковки, сут при 0…+6 °C | | по ТУ/результату |

## Фотофиксация (обязательно, свои фото, без стоков)
1. Упаковка с этикеткой и датой. 2. Ломтики на линейке. 3. Пицца до печи. 4. Пицца после печи (крупно).
5. Сравнение с батоном, нарезанным на месте (если делали).

## Что получится
- Обновлённые `/blog/narezka-pepperoni-parametry`, `/blog/pepperoni-for-pizzeria-horeca`.
- Блок «Испытано в печи» на `/pepperoni` с таблицей и фото (без превосходных степеней).
- Эти же числа — в Sheet (диаметр, толщина) → карточки KD-013/014 через sync.

## Что нельзя
- Публиковать оценочные значения («около 50 мм») без измерения.
- Сравнивать с конкурентами по названиям.
- Заявлять свойства, которых нет в протоколе.

Ответственный: технолог. Срок: неделя 3 плана. Приёмка: заполненный протокол + ≥5 фото в `docs/sprint-2026-09/bake-test/`.
